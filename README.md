# HDI-Prediction

## Overview
This project aims to predict the Human Development Index (HDI) using global economic and health indicators. Data was sourced from the United Nations Development Programme (UNDP) and the World Bank.

## Data Integration
- Merged datasets from multiple sources
- Cleaned and aligned country-level data across years
- Selected key predictors such as GDP per capita and health expenditure

## Methods
- Linear Regression (OLS)
- Correlation Analysis
- Log transformation of economic variables

## Key Findings
- GDP per capita and health expenditure showed strong relationships with HDI
- Log transformations improved linear relationships
- The model was able to capture meaningful global development trends

## Tools & Libraries
- Python
- pandas, numpy
- statsmodels
- matplotlib / seaborn

## Key Takeaway
This project demonstrates how combining multiple real-world datasets can provide insights into global development and the factors that drive human well-being.
